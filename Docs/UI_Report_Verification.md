# 토탈워 UI 보고서 — 검증 결과

> 대상: 사용자가 제시한 토탈워 전투 UI 구성 보고서
> 방법: 보고서의 각 항목을 RTXX 실제 코드와 1:1 대조
> 일자: 2026-08-04

---

## 0. 요약

보고서는 **토탈워 시리즈의 UI 설명으로는 정확합니다.** 다만 이것은
"RTXX에 이미 있는 것"이 아니라 **"토탈워에 있는 것"**입니다. 그대로
구현 지시로 읽으면 이 게임에 없는 시스템(마법, 영웅, 3D 초상화)까지
만들어야 합니다.

대조 결과 세 부류로 나뉩니다.

| 분류 | 개수 | 뜻 |
|---|---|---|
| 이미 있음 | 7 | 구현 완료. 검증함 |
| 만들 수 있음 | 6 | 데이터는 있고 표시만 없음 |
| 근거 없음 | 5 | 그 시스템 자체가 게임에 없음 |

---

## 1. 이미 있음 (검증 완료)

| 보고서 항목 | 구현 | 위치 |
|---|---|---|
| 전력 균형 막대 | 있음 | `UI_Command_Bar.Draw_Top_Strip` |
| 부대 카드 (병력 막대) | 있음 | `Draw_Card_Bar` / `Draw_Card` |
| 사기 막대 + 붕괴 점멸 | 있음 | `Draw_Morale_Bar` |
| 피격 시 카드 강조 | 있음 | 카드 색 변조 |
| 병종·태세 아이콘 | 있음 | `UI_Icons` + DCSS `gui_skills_*` |
| 레이더 맵(부대 점) | 있음 | `UI_Minimap` |
| 진형 예상 오버레이 | 있음 | `UI_Command_Preview` |

**단, 위치가 보고서와 다릅니다.**
보고서는 미니맵을 **우측 상단**이라 했지만, 이 프로젝트의 미니맵은
**좌측 하단**입니다(`UI_Minimap.cs`의 `x = margin`). 토탈워도 좌하단이
관례이므로 보고서 쪽이 어긋난 것으로 봅니다. 옮길 이유는 없어 보입니다.

---

## 2. 만들 수 있음 (데이터는 있음, 표시가 없음)

우선순위 순입니다.

### 2-1. 탄약 표시 — 데이터 있음, UI 없음

보고서의 "갈색 막대 = 남은 탄약"은 **근거가 있습니다.**

    Army_Data.cs:950   유닛 1인의 총 탄약 수 (0 이하면 무한)
    Unit_Data.cs:132   남은 탄약. 사격할 때마다 1씩 감소

즉 탄약은 이미 시뮬레이션이 소비하고 있는데 **화면에 전혀 나오지
않습니다.** 궁병을 언제 물릴지가 이 값에 달려 있으므로, 표시가 없으면
플레이어는 화살이 떨어진 뒤에야 압니다. 카드에 막대 한 줄이면 됩니다.

**이번 목록에서 비용 대비 효과가 가장 큽니다.**

### 2-2. 상태 아이콘 (교전/이동/사격/패주)

열거형이 이미 있습니다.

    E_Unit_Move    이동 상태
    E_Unit_Fight   교전 상태
    E_Army_Morale  사기 단계(패주 포함)

DCSS 아이콘도 이미 5,231장 들어와 있어 새로 구할 것이 없습니다.
카드 위에 작게 얹으면 됩니다.

### 2-3. 일시정지 / 배속

`Time.timeScale`을 쓰는 코드가 **한 줄도 없습니다.** 즉 새로 만들어야
하지만, 만드는 것 자체는 간단합니다.

주의: 이 프로젝트는 `FixedUpdate` 기반 결정론 시뮬레이션이라
`timeScale`을 올리면 틱당 계산량이 그대로 늘어납니다. 9,600 유닛에서
2배속은 프레임 예산을 2배로 요구합니다. **배속은 실측 후에 범위를
정해야 합니다.**

### 2-4. 전투 타이머

`Battle_Manager`에 제한 시간 개념이 없습니다(`resultDisplayTime`은 결과
표시용). 승리 조건에 시간을 넣을지는 **기획 결정 사항**입니다. 넣지
않기로 하면 이 항목은 폐기해야 합니다.

### 2-5. 상세 정보 패널 (I 키)

수치는 전부 `Army_Data`에 있습니다(공격력, 장갑, 피로도, 사기).
패널만 만들면 됩니다. 단 **3D 초상화는 불가능합니다** — 아래 3장 참조.

### 2-6. 전술 조감 (Tab)

카메라는 직교 투영이라 "수직 상승"이 의미가 없습니다.
`orthographicSize`를 키우는 것으로 같은 효과를 냅니다.
`Camera_Player`에 이미 스크롤 줌이 있으므로 그 값을 토글하면 됩니다.

## 3. 근거 없음 (게임에 그 시스템이 없음)

| 보고서 항목 | 왜 불가능한가 |
|---|---|
| 마법 도감 / 마법의 바람 게이지 | 마법 시스템이 없습니다 |
| 영웅·군주 액티브 스킬 | 스킬 시스템이 없습니다 |
| 3D 초상화 | 유닛이 32px 2D 스프라이트입니다. 3D 메시가 없습니다 |
| 자유 사격 토글 | 사격은 이미 자동입니다. 통제 개념 자체가 없습니다 |
| 방어 모드(추격 금지) | **아래 3-1 참조 — 부분적으로 이미 있습니다** |

### 3-1. 방어/산병 모드는 이미 태세로 존재합니다

보고서가 별도 버튼으로 제안한 두 가지는 이 게임에서 이미 **태세**로
구현되어 있습니다.

    E_Army_Stance.Line       전열 유지 = 보고서의 '방어 모드'
    E_Army_Stance.Skirmish   적이 접근하면 물러남 = 보고서의 '산병 모드'

`UI_Command_Panel`이 이미 이 둘을 버튼으로 내놓고 있습니다.
**중복 구현하면 안 됩니다.** 이름만 다를 뿐 같은 기능입니다.

## 4. 조작 충돌 — 보고서대로 하면 깨지는 것

보고서의 키 배정을 그대로 적용하면 기존 기능이 사라집니다.

| 보고서 | 충돌 대상 | 결과 |
|---|---|---|
| **Spacebar = 정보 오버레이** | `Battle_Manager.keyCode_Start_Battle = Space` | **전투를 시작할 수 없게 됩니다** |
| P = 일시정지 | 없음 | 사용 가능 |
| Tab = 전술 맵 | 없음 | 사용 가능 |
| I = 상세 정보 | 없음 | 사용 가능 |
| ESC = 메뉴 | 없음 | 사용 가능 |

Spacebar는 배치 단계를 끝내고 교전을 시작하는 키입니다. 오버레이로
덮어쓰면 배치에서 빠져나올 방법이 없어집니다. 정보 오버레이가
필요하면 **다른 키(예: Alt)를 쓰거나, 전투 시작 키를 먼저 옮겨야
합니다.**

### 참고: 기존 충돌 회피 기록

같은 이유로 부대 그룹은 관례인 Ctrl+숫자 대신 **F1~F8**을 씁니다.
숫자는 태세, Ctrl은 선택 추가에 이미 쓰이기 때문입니다.
자세한 것은 `UI_Battle_TotalWar.md`의 3-4를 보십시오.

## 5. 권고 — 무엇을 먼저 할 것인가

```
1) 탄약 표시        데이터가 이미 있는데 안 보임. 가장 싸고 효과 큼
2) 상태 아이콘      열거형·아이콘 모두 확보됨
3) 일시정지(P)      복잡한 명령을 내릴 시간. 배속은 실측 후 결정
4) 상세 패널(I)     초상화 제외
5) 전술 조감(Tab)   직교 줌 토글
```

**하지 않을 것:** 마법, 영웅 스킬, 3D 초상화, 자유 사격 토글,
방어/산병 모드 버튼(태세와 중복).

**보류:** 전투 타이머 — 승리 조건에 시간을 넣을지 정해야 합니다.

## 6. 이번에 실제로 실행한 것 (배치모드)

에디터가 닫혀 있어 CLI로 실행하고 결과를 파일에서 확인했습니다.

| 작업 | 결과 | 검증 방법 |
|---|---|---|
| 타일 임포트 설정 재적용 | exit 0 | `spriteMeshType: 0` × 5,231 (전량 Full Rect) |
| 아틀라스 재빌드 | exit 0 | `DCSS_Tiles.spriteatlas` 존재 |
| 전투 계층 + HUD 배선 | exit 0 | Scene1에 HUD 4종 참조 각 1개 |
| HUD 아이콘 채우기 | exit 0 | `UI_Icon_Set` 씬 참조 1개 |

무기·방패 어긋남의 원인이던 Tight 메시는 **전량 Full Rect로
교정되었습니다.** 피벗 값은 `{0.5, 0}` 그대로 유지되었습니다.

### 남은 문제

`Unit.prefab`이 삭제된 옛 DCSS 시트의 guid(`de3718ee...`)를 아직 2곳에서
참조합니다. 런타임에는 `Unit._Start`가 스프라이트를 덮어쓰므로 플레이에
지장이 없지만, 에디터에서 프리팹을 열면 빈 스프라이트로 보입니다.
